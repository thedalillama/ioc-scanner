# Initial Dashboard Section Replacement

## Previous initial-dashboard sections

Before this change, the dashboard below the fixed CSF framework header presented these sections:

- Today
- What Looks Good
- What Needs Care
- What Changed
- Recovery
- Care Journey
- Protection
- Reports

## Replacement

The former **Today** tile and the seven other initial-dashboard sections are replaced by three equally sized starting tiles:

1. **Configuration** — workspace choices, beginning with the selected control catalogs.
2. **Automation** — the local scheduled work that gathers and refreshes information.
3. **Reports** — saved records and exported evidence.

The new Configuration tile is the entry point for selecting or deselecting a control catalog. Catalog selection only governs which mapped controls are offered when an action is created; it does not delete imported reference material, mappings, or already-linked actions.
